## 为什么要用cc-switch？

![image-20260508112902385](https://cdn.jsdelivr.net/gh/Qiuner/drawing-bed/2026/3/image-20260508112902385.png)

你有 Anthropic 的 Key、也有 OpenAI 的 Key，还在用几家国内供应商——每次想切换模型，就得打开一堆配置文件一个个改，改完还容易漏。
cc-switch 解决的就是这件事：你只需要在一个地方维护所有供应商的 Token，然后点击即切换，它自动把对应的配置写进 Claude Code、OpenClaw 等工具的配置文件，省去所有手动操作。
